About the Model

The pipeline preprocesses the input text (lowercasing, stop-word removal, tokenization), generates embeddings using a Keras embedding layer, reduces dimensionality with PCA, and classifies with a Quadratic Discriminant Analysis (QDA) model trained on publications from 110 top neuroscience journals.

Data sourced from PubMed, SCImago, OECD, and more.
